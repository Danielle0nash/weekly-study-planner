# Weekly Study Planner

An application for planning weekly study sessions.

## Features

- Subject scheduling
- Study duration
- Weekly study summary

## How to Use

Select a day and enter a subject and duration.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Create a study plan for Monday.
- [ ] Check the displayed duration and weekly total.
- [ ] Remove the plan and verify totals update.
